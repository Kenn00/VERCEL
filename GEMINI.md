# Gemini Agent Directives for SALI Workspace

This document defines system prompt directives and domain rules for Gemini models and AI Studio coding agents working on the SALI 3D Camera Verification & Depth Analytics application.

## Core Directives
1. **Maintain Full-Stack Key Isolation**: All Gemini model calls (`gemini-3.5-flash`) must be routed through `server.ts` endpoints (`/api/generate-qa-report` and `/api/generate-compare-report`). Never initialize `@google/genai` on the client.
2. **Precision QA Standard**: Evaluate dimensional error against a 5.0% production-ready threshold.
3. **Multi-Run Trend Analysis**: Support multi-dataset comparisons, analyzing spatial drift across historical camera calibration runs.
4. **Clean Engineering Outputs**: Reports generated by Gemini must be executive-grade markdown with actionable physical mounting recommendations and zero raw debug logs.
